Privacy Policy.

This privacy policy establishes how we process and
protect your personal information.

Pattens – Dynamics 365 Form Debugger (“the Extension”) is a Google & Microsoft Edge browser extension designed to help Dynamics 365 developers and marketers test and troubleshoot forms more efficiently.

The Extension provides utilities such as:
Appending a #d365mkt-nocache tag to Dynamics 365 Marketing asset URLs to bypass cache during testing.
Optional developer view features like element highlighting.
Checks forms across all your corporate websites easily.
The Extension is strictly a client-side developer tool. It does not collect, store, transmit, share any user or browsing data or is active when a form is not detected.

Data Collection
The Extension:
Does not collect personally identifiable information.
Does not track browsing activity or page content.
Does not communicate with any external server or analytics service.
Does not include advertising or telemetry.
All actions occur entirely within your browser and on your local machine.

Local Storage
The Extension uses Microsoft Edge’s chrome.storage.local API to save user preferences (for example, which toggles are active).

This data:
Is stored locally in your browser.
Is never transmitted to any server.
Is automatically deleted if the Extension is uninstalled.
No personal data is included or accessible.

Extension Permissions and Justification
activeTab | To apply changes (like toggles or hash appends) on the current webpage. | Only acts when the user activates the extension popup.
scripting | To inject small scripts that enable highlighting or parameter toggling. | Scripts are local and contain no tracking code. |
storage | To remember toggle states between sessions. | Stored locally in your browser. |
host_permissions: | Required for the toggles to function on Dynamics 365 pages. | The extension does not scan or collect page content. |

All permissions are limited to user-triggered actions and operate entirely within the local browser environment. No data is transmitted externally, collected, or shared.All permissions are essential for the extension’s intended debugging functionality and limited in scope.

Third-Party Services
The Extension does not use or connect to any third-party APIs, databases, or analytics platforms.

Security
Because no data leaves your local environment, there are no remote storage or network security risks. All code executes within the Microsoft Edge sandboxed extension environment.

Children’s Privacy
The Extension is intended for professional and technical users (Dynamics 365 developers and marketers). It does not knowingly collect information from children under 13.

Changes to This Policy
If the Extension’s behavior or permissions change in future updates, this Privacy Policy will be updated and versioned in the public GitHub repository. The Edge Add-ons listing will always reference the latest version.
