Dynamics 365 Form Debugger privacy.

This page explains how the browser extension handles data, permissions, storage, and privacy.

Last updated

June 25, 2026

GitHub repo Chrome store Edge add-on

Dynamics 365 Form Debugger is a Chrome and Microsoft Edge browser extension designed to help Dynamics 365 developers and marketers test and troubleshoot forms more efficiently.

What The Extension Does

The extension is a client-side developer tool. It can append a #d365mkt-nocache tag to Dynamics 365 Marketing asset URLs to bypass cache during testing, provide optional developer-view features such as element highlighting, and help check forms across corporate websites.

The extension does not collect, store, transmit, or share browsing data. It is active only when a user interacts with the extension or when a supported form workflow is detected.

Data Collection

The extension does not:

  • Collect personally identifiable information.
  • Track browsing activity or page content.
  • Communicate with external analytics services.
  • Include advertising, telemetry, or remote data collection.

All extension actions occur in your browser on your local machine.

Local Storage

The extension uses the browser's local extension storage API to save user preferences, such as which toggles are active.

  • Preference data is stored locally in your browser.
  • Preference data is never transmitted to a server.
  • Preference data is automatically deleted when the extension is uninstalled.
  • No personal data is included or accessible.

Permissions

The extension requests only the permissions needed for its debugging functionality:

  • activeTab lets the extension apply user-triggered changes to the current page.
  • scripting lets the extension inject small local scripts for highlighting or parameter toggles.
  • storage lets the extension remember toggle states between browser sessions.
  • host_permissions let the extension function on supported Dynamics 365 pages without scanning or collecting page content.

All permissions are limited to user-triggered actions and operate within the local browser environment.

Third-Party Services

The extension does not connect to third-party APIs, databases, analytics platforms, advertising networks, or telemetry services.

Security

Because no extension data leaves your local browser environment, there is no remote storage layer for extension data. Code runs inside the browser extension environment provided by Chrome and Microsoft Edge.

Children's Privacy

The extension is intended for professional and technical users, including Dynamics 365 developers and marketers. It does not knowingly collect information from children under 13.

Changes To This Policy

If the extension behavior or permissions change in a future update, this privacy policy will be updated and versioned publicly.
