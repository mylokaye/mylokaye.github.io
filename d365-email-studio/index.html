Dynamics 365 Email Studio

Dynamics 365 Email Studio

Edit and translate existing Dynamics 365 email HTML with protected markup and local structural validation.

Focused email editing

Dynamics 365 Email Studio is a free plugin by Mylo Kaye for constrained content edits and translations to existing Dynamics 365 Customer Insights – Journeys email HTML. It preserves layout, Dynamics expressions, tracking, compliance links and Outlook markup.

How to use it

  1. Select the plugin in Codex and supply an existing HTML email with the specific wording or translation you need.
  2. Keep the original file. The skill saves a separate edited file and runs the bundled Python structural validator locally.
  3. Review the complete HTML and diff, then check Dynamics preview and a test send before use.

A local executor with Python 3 is required for structural verification. The plugin does not create or redesign emails, connect to your Dynamics tenant, send messages or publish campaigns.

Cloudflare connection

The read-only MCP server provides only the editing guide and validator source. Both tools take no arguments. Email HTML must not be submitted to that server. OpenAI processes chat inputs and attached content according to your account settings and its policies; local validation does not mean that chat content stays off OpenAI systems.

Get the plugin

Open Dynamics 365 Email Studio. Availability depends on the plugin’s current access and review status. Inspect the source on GitHub.
