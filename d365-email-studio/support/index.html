Dynamics 365 Email Studio

Email Studio support

Get help with Dynamics 365 Email Studio, report a problem or ask a privacy question.

Contact support

Email mylo@mylokaye.com with “Dynamics 365 Email Studio” in the subject. This is also the contact for privacy requests.

Report a problem

Include the plugin version, the change you requested, your operating system and Python version, and the validator error. Use a minimal synthetic example where possible. Remove names, customer details, credentials, tracking identifiers and confidential content before sending files or screenshots.

You can also report an issue on GitHub. GitHub issues are public, so do not post personal or confidential data there.

Common checks

  • Use an existing email HTML file and keep an untouched original.
  • Ensure Python 3 and local execution are available.
  • Request wording or translation changes within the skill’s allowlist.
  • Use Dynamics preview and a test send to check rendering and tenant behaviour.

Support is provided as available, with no guaranteed response time. Support messages are kept only as needed to resolve the request.
