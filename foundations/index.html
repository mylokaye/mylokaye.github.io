Foundations

A small library of reusable agent plugins for consistent project delivery, plugin authoring, web work, and JavaScript static review.

Release status

Available from source. Fresh-client installation checks and plugin catalog publication are still pending.

Explore Foundations on GitHub

Reusable skills with clear boundaries

Foundations separates technology-neutral project practices from focused guidance for web implementation, JavaScript-family code review, and agent-plugin authoring. The packages are designed to remain useful without prescribing a framework, UI toolkit, cloud provider, or deployment system.

Included packages

  • foundations.project — documentation, design, accessibility, privacy, verification, and scoped delivery.
  • foundations.authoring — portable plugin structure, manifests, validation, and release readiness.
  • foundations.web — semantic HTML, CSS systems, and browser JavaScript.
  • foundations.javascript-static-review — static review for JavaScript, TypeScript, React, Next.js, and browser extensions.

Install from source

Clone the repository and select one package directory: project/, authoring/, web/, or javascript-static-review/. The repository does not yet claim fresh-client compatibility or publication to a plugin catalog; its README tracks those checks as pending.

Project boundaries

Use the project package as the shared base. The web, static-review, and authoring packages add focused practices for their own work areas. Specialist platform conventions belong in separate plugins so each package remains useful on its own.
