Agentic Form

A portable two-step inquiry-form prototype with validation, optional company enrichment, editable suggestions, and a local-only prototype submission flow.

Prototype boundary

Submit and feedback actions are demonstrations. They do not send form data or store ratings in a production backend.

Try the hosted prototype View Agentic Form on GitHub

A progressive two-step inquiry

The browser UI, styles, and interaction logic live in a portable HTML file. Optional company enrichment runs through a local development proxy or hosted worker so the service credential stays out of the browser.

Step 1: inquiry

The first step collects name, email, inquiry, business, and inquiry type. Required personal fields are validated before continuing. An inquiry-type suggestion can be requested from TypeSafe, and company details can be suggested from the email domain. Suggestions remain editable.

Step 2: personal details and submit

The second step collects phone, role, language, company, industry, country, and a state when the selected country is the United States. Browser language can provide an editable suggestion. A country lookup can suggest a country and international phone prefix.

Submitting shows the prototype thank-you screen and does not send the inquiry to a CRM or submission service. Five feedback buttons change the confirmation state; the rating is not stored or transmitted.

Optional enrichment and privacy

Enrichment is advisory, can fail without blocking the form, and should be reviewed before production use. The current repository documents Google Analytics events and a country-lookup request. Review those network interactions and any applicable consent requirements before deploying the prototype in a production context.

Prototype boundaries

Agentic Form is an implementation prototype, not a production inquiry-submission system. Browser regression coverage does not verify a CRM integration or production service.
